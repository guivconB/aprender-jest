# AGENTS.md — Aprender Jest

> Arquivo de contexto e memória do projeto de estudos **aprender-jest**.

## Visão Geral

* **Objetivo:** Exercícios de testes com **Jest** e **Supertest**: funções puras em `app.js` e uma API **Express** em `server.js` (testes em `app.test.js`, `server.test.js`, `desafio-404.test.js`).
* **Comando:** `npm test`.
* **Diretriz:** Ao criar novos desafios ou rotas de estudo, acompanhe sempre com testes Jest correspondentes.
